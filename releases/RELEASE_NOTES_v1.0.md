# Armies of Gielinor – Official Standalone Release (v1.0)

Welcome to the definitive standalone release of **Armies of Gielinor**, the turn-based tactical strategy game from the RuneScape universe, fully preserved for modern 64-bit Windows.

---

### Highlights & Key Features

- **Singleplayer Campaign & Custom Skirmish:** Complete all 17 campaign missions and create custom battles against computer opponents across every map.
- **Steam Multiplayer Integration:** Seamless online play with friends using standard Steam friend invites and lobbies.
- **Dynamic Asset Streaming & Portable Cache:** Bundles the complete game cache with automatic on-demand streaming fallback, ensuring smooth loading on all hardware.
- **Zero Setup Required:** Includes a self-contained, pre-configured Java 18 runtime. No external Java installation is needed.
- **Illustrated Manual:** Comes with the complete 31-page illustrated guide (`Manual.pdf`) detailing all 75 units, gods, spells, and game rules.

---

### Quick Start Guide

1. Download and extract **`ArmiesOfGielinor_v1.0.zip`**.
2. Keep **Steam** running in the background.
3. Launch **`ArmiesOfGielinor.exe`** and play!

---

### System Requirements

- **OS:** Windows 10 or Windows 11 (64-bit)
- **RAM:** 2 GB minimum
- **Disk Space:** ~150 MB free space
- **Steam Client:** Running in the background (required for player identity and multiplayer invites)
