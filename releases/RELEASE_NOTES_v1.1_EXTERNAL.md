# Armies of Gielinor – Update v1.1 (Multiplayer & Invite Fixes)

This update resolves an issue where the game could freeze or crash to a black screen when joining Steam friend invites.

---

### What's New
- **Fixed Steam Invite Black Screen:** Joining matches via Steam friend invites is now smooth and reliable.
- **Automatic Connection Retry:** Delayed initial connections are retried automatically without needing to restart the game.
- **Complete Stability:** All campaign missions, custom skirmish battles, and multiplayer modes run smoothly.

> **Multiplayer Tip:** All players in the lobby should update to ensure seamless compatibility.

---

### System Requirements
- **OS:** Windows 10 or Windows 11 (64-Bit)
- **Steam:** Must be running in the background (for Steam names and friend invites)
- **Java:** **Not required!** The bundled Java runtime is included.

---

### Quick Start
1. Download and extract **`ArmiesOfGielinor_v1.0.26.zip`**.
2. Keep **Steam** running in the background.
3. Launch **`ArmiesOfGielinor.exe`** and play!
