# Armies of Gielinor – Standalone Edition (v1.0.6)

The turn-based strategy game from the RuneScape universe — fully playable on modern PCs as a standalone release with complete singleplayer campaign and Steam multiplayer.

---

### System Requirements
- **OS:** Windows 10 or Windows 11 (64-Bit)
- **RAM:** Minimum 2 GB free RAM
- **Storage:** ~150 MB free disk space
- **Steam:** Steam running in the background (required for player names and multiplayer invites)
- **Java:** **Not required!** The bundled Java runtime is included.

---

### Features
- **Singleplayer Campaign & Skirmish:** Play all missions and maps against AI opponents.
- **Steam Multiplayer:** Host lobbies and invite friends directly through the Steam friends list.
- **Illustrated Manual (`Manual.pdf`):** A 31-page guide covering all 75 units, gods, spells, and rules is included.

---

### Quick Start
1. Download and extract **`ArmiesOfGielinor_v1.0.6.zip`**.
2. Keep **Steam** running in the background.
3. Launch **`ArmiesOfGielinor.exe`** and play!
